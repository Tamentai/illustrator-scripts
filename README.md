# Illustrator Scripts

Adobe Illustratorで多角形・星形多角形を作図するためのExtendScript（JSX）スクリプト集です。

幾何学的な作図や、多面体・造形制作のための図形生成を目的として作成しています。

## Scripts

### star_polygon_generator.jsx

正多角形および星形多角形 `{p/q}` を生成するスクリプトです。

#### 主な機能

- 頂点数 `p` を指定
- 飛ばし数 `q` を指定
- 外接円半径を指定
- 回転角を指定
- 線幅を指定
- 行・列を指定して複数の図形を一括配置
- 横方向・縦方向の配置間隔を指定
- 外接円の表示
- 頂点番号の表示

#### `{p/q}` について

`p` は頂点数、`q` は頂点を結ぶ際の飛ばし数です。

例：

- `{5/1}` : 正五角形
- `{5/2}` : 五芒星
- `{7/2}` : 七芒星
- `{7/3}` : 七芒星

`q = 1` の場合は通常の正多角形になります。

`p` と `q` が互いに素でない場合は、複数の独立した閉路として描画されます。

### star_shape_from_selected_edge_v3.jsx

Illustrator上で選択した1本の直線を基準として、星形図形を作図するスクリプトです。

基準となる直線の長さから図形全体の大きさを計算するため、寸法を意識した幾何学的な作図に利用できます。

#### 描画形式

2種類の描画方法を選択できます。

**星形多角形 `{p/q}`**

選択した直線を `{p/q}` の1辺として扱い、線が交差する星形多角形を作図します。

**星型の輪郭 `☆`**

交差型の `{p/q}` と同じ外形サイズを持つ、外頂点と内頂点を交互に結んだ星型の輪郭を作図します。

内半径は、

- `{p/q}` の交点から自動計算
- 外半径に対する割合を手動指定

のどちらかを選択できます。

#### 主な機能

- 選択した直線を基準に作図
- 頂点数 `p` を指定
- 飛ばし数 `q` を指定
- 線幅を指定
- 交差型の星形多角形を生成
- 星型の外形パスを生成
- 内半径を自動計算または任意指定
- 基準線の左右どちら側に作図するか選択
- 外接円の表示
- 頂点番号の表示
- 元の基準線を残す／削除

#### 使い方

1. Illustratorでドキュメントを開きます。
2. 直線ツールなどで直線を1本作成します。
3. その直線だけを選択します。
4. `star_shape_from_selected_edge_v3.jsx` を実行します。
5. `p`、`q`、描画形式などを設定します。
6. 「作成」をクリックします。

基準として使用できるのは、2つのアンカーポイントからなる開いた直線パスです。

## Installation

JSXファイルをAdobe Illustratorのスクリプトフォルダにコピーします。

macOSのIllustrator 2026日本語版の場合、一般的には次のような場所です。

```text
Adobe Illustrator 2026/
└── Presets.localized/
    └── ja_JP/
        └── スクリプト/
```

Illustratorを再起動すると、

**ファイル → スクリプト**

からスクリプトを実行できるようになります。

スクリプトファイルを任意の場所に保存し、Illustratorの

**ファイル → スクリプト → その他のスクリプト...**

から直接実行することもできます。

## Requirements

- Adobe Illustrator
- ExtendScript（JSX）が実行可能なIllustrator環境

現在はmacOS版 Adobe Illustrator 2026で作成・動作確認しています。
